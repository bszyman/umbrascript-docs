# Get started

Install UmbraScript, enable the backoffice section for your user group, and run a read-only command against your content tree.

## Before you begin

You need:

- An Umbraco CMS 17 or later website
- Access to the project that contains the Umbraco `.csproj` file
- Permission to restart the website
- An Umbraco backoffice account

## Your path to a first result

1. [Install and enable UmbraScript](install.md).
2. [Run your first command](first-command.md).
3. Learn how [references and selections](../language/references-and-selections.md) identify items in a tree.
4. Use the [command reference](../reference/index.md) when you are ready to do more.

!!! warning
    Several UmbraScript commands change content or media immediately. Read [Permissions and safe use](../administration/permissions-and-safety.md) before running a batch or destructive command on a production site.
